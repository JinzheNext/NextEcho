# 外部文本对齐候选

Qwen3-ForcedAligner属于显式实验适配器，用于在本机为既有文字测量对齐证据，不是本版默认识别或分人后端。未通过时间轴质量验收时不能声明precise字幕可用，不按字数比例伪造时间。

固定模型与代码声明、hash和尚未解决的分发条件见[模型许可证台账](model-license-inventory.md)。原生权重、独立PyTorch/Transformers环境、测试音频与中间对齐输出不随程序或Skill分发。普通安装和run不下载这些资产。

使用者须单独绑定实际模型、worker、来源与资源预算；文字匹配率和有效正时长区间覆盖分别检查。缺文件或不可信测量应明确失败，不修改原稿来制造匹配。安装包内仅提供适配代码，不提供质量放行或模型再分发许可。
