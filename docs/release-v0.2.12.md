# v0.2.12 Agent Skill 预览发布

本版把已在本机使用的Agent工作流、安装器和阅读交付整理为公开源代码与下载包。它是软件预览发布，不将模型候选或待审字幕提升为生产ready。

## 下载内容

- 完整Agent ZIP：Skill、程序wheel、对应源码tar.gz、安装器、依赖约束、许可证与文件清单。
- 纯Skill ZIP：供已有兼容NextEcho运行时的机器使用，包含LICENSE与NOTICE。
- 独立wheel和对应源码包，以及SHA256SUMS.txt。

Python解释器、FFmpeg、whisper-cli、yt-dlp、Ollama/其他模型服务、模型权重、用户配置、绑定、媒体和声纹资产均不内置。核心Python依赖按约束在安装时获取，模型worker独立准备。

## 本版行为

用户获准的个人候选组合可按精确模型ID保存，普通链接调用无需每次补profile。未获准候选与文件/资源限制保留。安装器备份旧Skill与绑定，备份在技能发现目录之外。

auto分人缺少可选资产时交付完整文字并记录partial，required及损坏/hash错误仍阻断。润色数值、否定、条件与元字段校验未通过时保留原文。partial、完整音频覆盖、处理完成和身份待审分列，不把一个状态当成全部失败或成功。

阅读稿使用作者确认的顶部文案、Obsidian标题链接、捕获的公开评论原文与审计阅读整理。未确认身份的通用显示标签为“发言人1”，不更改原稿声学ID，也不将其当作已确认自然人身份。

## 验证范围与对应源码

发布分支执行完整纯逻辑/编排回归，模型推理边界使用测试替身；真实本机试跑与人工质量判断独立。包内容审计排除权重、二进制媒体、凭证和个人绑定，源码重建及独立安装记录随发布验收保存在维护者本地。公开回归样例移除原转录摘录和本机目录，保留结构与升级契约；原始私有样例不发布。

应用代码遵循仓库AGPL-3.0-only，LICENSE未更改。wheel提供对应源码，完整Agent包也内置同版本源码。所有模型、代码运行时、转换物的外部许可与来源仍按第三方台账分别核对；本版不授予未捆绑模型的使用或再分发许可。
